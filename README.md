## Task 1 — Landing Page

Responsive **SmartLearn** landing page featuring:

* Sticky navigation
* Hero section
* CTA button
* Features and About sections
* Footer
* Responsive design

**Tech:** HTML, CSS

## Task 2 — Personal Portfolio

Responsive personal portfolio containing:

* Hero/profile section
* About Me
* Skills
* Projects
* Contact section
* Smooth scrolling

**Tech:** HTML, CSS

Interactive temperature converter supporting:

* Celsius
* Fahrenheit
* Kelvin
* Input validation
* Absolute-zero validation
* Reset functionality

**Tech:** HTML, CSS, JavaScript

# Level 2

## Task 1 — Calculator

Browser-based calculator with:

* Basic arithmetic operations
* Decimal support
* Backspace and Clear
* Division-by-zero handling
* Operator chaining
* Keyboard support

**Tech:** HTML, CSS, JavaScript

## Task 2 — Tribute Page

Responsive tribute page dedicated to **Abdul Sattar Edhi** featuring:

* Biography
* Image
* Quote
* Timeline
* Achievements and legacy

**Tech:** HTML, CSS

## Task 3 — To-Do Web App

Interactive task manager with:

* Add tasks
* Edit and delete
* Complete/undo tasks
* Pending/completed counters
* Timestamps
* localStorage persistence

**Tech:** HTML, CSS, JavaScript

## Task 4 — Login Authentication System

Client-side authentication demonstration including:

* Registration
* Login
* Password validation
* Duplicate-user checking
* SHA-256 password hashing
* Protected dashboard
* Logout
* localStorage and sessionStorage

> This authentication project is for learning purposes and is not intended for production use.

**Tech:** HTML, CSS, JavaScript, Web Crypto API
